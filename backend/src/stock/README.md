# Stock represents a stock in a given instrument

## Use cases:

- Setup a stock on Demand
  - Add a stock to stock_master
  - Create a table for the stock with name stock\_{SYMBOL}
  - Every stock is mutually exclusive of every other stock
- Read a stock
  - SQL queries that are generated by Stock Agent
- Update a stock
  - Only INSERTs, as it is timeseries data
- Delete a stock
  - Temporarily archive a stock if not used for 3 months

## Integration with a Vendor

- Fetch Historical Data on demand
- Open a websocket for ticker data and subscribe to the instruments in one shot

## Agent:

- Works only to write SQL queries on stock data based off of the input

## REST APIs:

- POST API to setup a stock
- POST API to update a stock
- DELETE API to delete a stock
- POST API to setup Historical data

## Websocket:

- Listen to ticker data
